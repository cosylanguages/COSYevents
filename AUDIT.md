## 1. Taxonomy & Architecture

### Single Source of Truth Catalog Architecture
- **Root Format & Topic Catalogs (`<topic>.html`):** The primary interactive catalog pages reside at the repository root (`speaking-clubs.html`, `cinema-club.html`, `karaoke-club.html`, `game-evenings.html`, `long-reads.html`, `basic-speaking-club.html`, `debatable-relatable.html`, `i-couldnt-help-but-wonder.html`, `if-you-were.html`, `keeping-up-with-science.html`, `lets-celebrate.html`, `mind-matters.html`, `my-life-with-without.html`, `the-greatest-quotes.html`).
- **Category Hubs (`<category>/index.html`):** Filter hubs for calendar views (`speaking-clubs/index.html`, `cinema-nights/index.html`, `teacher-led-sessions/index.html`, `special-events/index.html`).
- **Taxonomy Subfolder Index Routes (`events/speaking-clubs/*/index.html` and `events/multimedia-nights/*/index.html`):** The 12 subfolder index pages act as client-side redirect routes pointing seamlessly to their canonical root catalog pages (`../../../<topic>.html`), ensuring URL compatibility across sibling ecosystem repositories (`cosylanguages`, `cosydata`, `cosyplatform`).

### Site Configuration
- **Sitemap:** `sitemap.xml` is generated by `scripts/generate-sitemap.js` (`npm run build-sitemap`) and lists only public, indexable pages (root catalogs, hubs, and session pages). Error pages, auth surfaces (`login.html`, `account.html`, `studio.html`, `live-classroom.html`), authoring `templates/`, and client-side redirect stubs are excluded. Verify freshness with `npm run check-sitemap`.
- **Robots:** `robots.txt` allows all crawlers and points to the sitemap.
- **Content pipeline:** Session content is authored as repository files (Markdown frontmatter under `sessions/<club>/*.md` and standalone HTML). There is no external CMS configuration.

## 2. Session Content & Catalog Verification

### Master Catalog Statistics (`data/sessions.json`)
- **Total Session Files on Disk:** 644 standalone HTML session pages across all supported languages:
  - English Sessions (`sessions/`): 560 files
  - French Sessions (`fr/sessions/`): 43 files
  - Russian Sessions (`ru/sessions/`): 41 files
- **Total Catalog Entries in `data/sessions.json`:** 650 entries. All 644 disk files are cataloged; the 6 extra entries are the individual Game Evening titles that share the `game-evenings.html` landing page and drive the Games filter in the session directory.
- **Master Calendar Records (`shared/calendar-data/events.json`):** 19 scheduled event entries.

### Repository-First Session Content Model
- **Canonical source:** Complete session materials are stored as repository files, including the standalone HTML session pages under `sessions/`, `fr/sessions/`, and `ru/sessions/`, plus structured JSON under `events/<event-slug>/sessions/`.
- **Static discovery index:** `public-events.json` is a lightweight listing index, not the authoritative store for full session content.
- **No Supabase session body dependency:** Session page rendering must not read session bodies, vocabulary, facilitator notes, or prompts from Supabase. The legacy session-content tables may still exist in the shared project, but COSYevents no longer publishes to or reads from them.
- **Public access warning:** This is a public repository. Committed files and Git history are publicly accessible; do not commit secrets, personal data, or material that is not authorized for public distribution.

## 6. Automated Verification Tooling

Active verification scripts in `scripts/`:
- `verify_catalog.js` — Confirms 1:1 catalog mapping between `data/sessions.json` and disk HTML files (also checks level parity). Wired into CI.
- `check_hub_links.js` — Validates relative link integrity across localized hubs.
- `verify_hub_linkage.js` — Ensures 100% of localized sessions are displayed and linked on hub pages.
- `check_orphan_classes.js` — Reports CSS classes referenced in hub pages but defined in no loaded stylesheet. Wired into CI via `npm run check-orphans`.
- `generate-sitemap.js` — Builds `sitemap.xml`; `--check` mode (`npm run check-sitemap`) fails if the committed sitemap is stale. Wired into CI.
- `check-gated-pages.js` — Enforces the gated-content contract (`npm run check:gated`).
- `check_links.js`, `check-structure.js`, `check-names.js` — Link, structure, and naming policies.
