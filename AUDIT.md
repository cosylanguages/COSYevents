## Critical issues (must fix before launch)
- [ ] Navigation broken or unusable on mobile
- [ ] Primary event action (view, join, register) hard to find or use
- [ ] Text too small / poor contrast
- [ ] Buttons/inputs too small or too close together
- [ ] Horizontal overflow / clipped content on small screens
- [ ] Missing focus states / keyboard navigation broken
- [ ] Feedback only via color (no text/icon/pattern)
- [ ] Missing loading / error / empty states for key flows
- [ ] Date/time or timezone information unclear or inaccessible

## High priority
- [ ] Long event titles or descriptions break layout
- [ ] Event filtering, search, or calendar views unclear
- [ ] Registration or participation flow has unclear steps or states
- [ ] Images/assets too heavy or slow on mobile
- [ ] Event details (location, link, host) hard to find or trust
- [ ] Reading layout is difficult on mobile or at large text sizes

## Medium / Low
- [ ] Visual hierarchy unclear
- [ ] Too many similar-looking cards or panels
- [ ] Overuse of decorative effects (gradients, glass, etc.)
- [ ] Inconsistent spacing / typography
- [ ] Event collections or series are difficult to browse or resume
