📖 Session Vocabulary

COSYlanguages Philosophy & Developer Vocabulary Guidelines:
1. Fully Monolingual: Absolutely no translation fallback. All content, definitions, and examples must be written entirely in the target language. Utilize emojis, context, symbols, and graphics to guide learners instead of translations.
2. Vocabulary Acquisition Pillars: Focus on helping learners master words/phrases through:
  • Definitions: Clear, simple target-language definitions.
  • Opposites & Antonyms: Always document contrasts where applicable using the Word ≠ opposite format.
  • Associations & Collocations: Provide phrases and typical word partners in the target language.
  • Images & Graphics: Leverage single emojis (and in games/practice, visual card layouts) to make elements memorable.
3. Strict Data Privacy (Zero Collection): We collect absolutely zero data of learners and teachers. No server databases, no registrations. All notebook words, metrics, and custom lists are stored completely client-side via localStorage.
4. Direct Extraction: All vocabulary, collocations, or set phrases must be extracted directly from targeted session sources (articles, videos, songs, films, series, etc.). Read or watch the source material completely before compiling.
5. Diversified Types: Do not limit entries to single word units. Include relevant set phrases, collocations, idioms, or useful phrasal verbs that are highly applicable to the discussion.
6. 10-10-10 Rule: Exactly 10 units are required. Each entry must have a word, definition, and example ending with a period.
7. Antonym / Opposition Extension: For vocabulary units that have an obvious opposition (like optimism, active, la liberté, etc.), expand the student's vocabulary by documenting both opposites in the following format: Word ≠ opposite in the .vocab-word block (and inside COSY.addToDict), with definitions and examples reflecting both/contrasts (e.g. Word definition ≠ opposite definition and an example comparing them).

✏️ Teacher's Note (Linguistic Corrections)▲
Developer Correction & Feedback Guidelines:
1. Do not cross out or strike through the whole sentence. Accentuate/highlight specific errors using the three error-type system below.
2. 1. Extra/Wrong Word: On the wrong side, wrap ONLY the erroneous word in <span class="mistake-flag-wrong">. On the correct side, wrap the replacement in <span class="mistake-flag-right"> (or use <span class="mistake-null">X</span> for pure deletion).
3. 2. Missing Word: On the wrong side, place <span class="mistake-null">X</span> at the gap. On the correct side, wrap the inserted word in <span class="mistake-flag-right">.
4. 3. Word Order / Structure: On BOTH sides, wrap matching sentence constituents in mistake-part-subj (Subject), mistake-part-verb (Verb), mistake-part-obj (Object), mistake-part-mod (Modifier), or mistake-part-other so reordering is visually traceable by color. Do not use flag or null classes in this mode.
5. Level-Appropriate Diversification: Starter/Elementary (basic grammar/vocab swaps), Intermediate (word order/structure or collocations), Advanced (register/nuance adjustments or direct deletions).
He have went to Paris → He has gone to Paris (Wrong word: 'have' vs singular auxiliary 'has' for present perfect)
We discussed yesterday the problem → We discussed the problem yesterday (Word order: Verb + direct object + temporal adverbial modifier)
We discussed about the problem → We discussed X the problem (Extra word deletion: 'discuss' is transitive and takes a direct object without 'about')
